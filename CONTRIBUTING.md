# Contributing

Thanks for the interest!

## Code style

We use Dart's default formatter. Internal PRs are auto-formatted by CI, but
PRs from forks aren't (CI can't push back to forks). Before pushing from a
fork, run:

```sh
dart format lib test
```

CI will reject unformatted code on fork PRs.
